# Bali Trip Planner — единая цветовая система

- `styles.css`: все цвета определены в самом первом блоке `:root`. Для изменения оттенка редактируйте значение переменной там.
- `index.html`: русский текст записан обычными буквами UTF-8, а не HTML-сущностями.
- `app.js`: расчёты, данные и обработчики сохранены. Изменена только разметка строки разбивки расходов: её цвет границы теперь управляется CSS.

## Обновление GitHub Pages
Замените в корне репозитория три файла `index.html`, `styles.css`, `app.js`. После Commit дождитесь публикации и перезагрузите страницу.

## Данные
Ключ `localStorage` прежний: `baliTripPlannerV2`. Изменения файлов не удаляют данные браузера. На всякий случай перед обновлением используйте кнопку «Скачать данные».
