## Как опубликовать на GitHub Pages

1. Сначала скачай резервную копию текущих данных на сайте кнопкой «Скачать данные».
2. Открой свой репозиторий GitHub.
3. В корне репозитория должны лежать **три файла рядом**: `index.html`, `styles.css`, `app.js`.
4. Загрузи эти файлы через **Add file → Upload files**, заменив старый `index.html`.
5. Нажми **Commit changes**. GitHub Pages автоматически обновит сайт.
6. Открой сайт и обнови страницу без кеша (`Cmd + Shift + R`).

**Важно:** если загрузить только `index.html`, оформление и калькулятор не заработают: ему нужны два соседних файла.

## Как устроена страница

- **HTML**: смысл и порядок разделов. `<header>` — шапка, `<main>` — содержимое, `<section>` — смысловой блок, `<h2>` — заголовок, `<div>` — контейнер, `class` — имя стиля, `id` — идентификатор для JavaScript.
- **CSS**: визуальные свойства. `color` — цвет текста, `background` — фон, `padding` — внутренние отступы, `border-radius` — скругление.
- **JavaScript**: значения полей, расчёт суммы, переключение сценариев, локальное сохранение.

## Совместимость

- Ключ сохранения `baliTripPlannerV2` не изменён. Старые данные в том же браузере и на том же адресе сайта должны загрузиться.
- Никакая база данных не добавлена: данные по-прежнему хранятся локально у каждого посетителя.
- Это реорганизация исходного кода, а не переписывание функциональности.


## Обновление: понятные функции и бюджетные статусы

В `app.js` обработчики событий теперь названы по действиям: `updateTravelDate`, `preserveNightsRatio`, `updateCurrency`, `handleFieldChange`, `handleSliderInput`, `sharePlan`, `exportPlan`. Расчёт сметы находится в `calc`, а коэффициенты расходов — в `expenseMultiplier`.

В `styles.css` интерактивный акцент — `--color-accent`, а цвет положительного финансового статуса — `--color-success`. Сейчас он равен `#247A61` (спокойный нефритовый зелёный). Фон плашки задаётся через `--color-success-soft`. Превышение бюджета оформлено красным через `--color-danger`.

При обновлении загружайте `index.html`, `styles.css` и `app.js` вместе. Ключ сохранения `baliTripPlannerV2` не менялся.
